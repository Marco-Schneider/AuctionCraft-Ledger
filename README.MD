<h1 align="center">AuctionCraft – Ledger</h1>

<p align="center">
  A lightweight World of Warcraft addon that calculates the total gold value of your active auctions. When managing multiple auctions, it's not trivial to quickly estimate total returns. This addon aims to provide that insight instantly, without clutter.
</p>

## About

**AuctionCraft – Ledger** listens to Auction House events and aggregates the value of your listed auctions, giving you a clear overview of your expected earnings.

This addon was created both as a way to dive into the WoW addon programming world as well as a starting point for a planned integration with other systems currently being developed by me. Stay tuned for more!

## Features
*  Calculates total expected gold from active auctions
* Lightweight and fast
* Built as part of the AuctionCraft addon ecosystem (WIP)

## Installation

### Option 1 - CurseForge
Download directly from CurseForge (recommended)

### Option 2 - Manual Install
1. Download the latest release
2. Extract its content into
```
World of Warcraft/_retail_/Interface/AddOns/ 
```
3. If already in-game, just run the following command on the chat window:
```
/reload
```
